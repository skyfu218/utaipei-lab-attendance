# 臺北市立大學運動能力分析實驗室打卡系統

手機掃描 NFC Tag 的行動出勤 Web App。正式後臺採 Firebase Spark 免費方案。

## 目前可操作功能

- Google 帳號登入、待核准與系統總管權限
- 待核准帳號的核准、不核准、停用與重新開通流程
- 帳號審核理由及不可竄改的操作紀錄
- NFC 簽到與簽退流程
- 重複掃描防止重複紀錄
- 個人及全體出勤紀錄
- 請假、補登及更正申請
- 異常與申請中心
- 出勤事件訊息中心
- 管理者對個別同仁傳送站內提醒
- 人員與 Tag 管理畫面
- 共用班表、遲到寬限與排除日期設定
- 每月遲到、早退、缺卡、請假及公出統計
- 原始出勤紀錄與月報 CSV 匯出
- 響應式手機介面與 PWA 基礎

## NFC 網址參數

- 簽到：`?tag=lab-checkin`
- 簽退：`?tag=lab-checkout`

## Firebase 免費模式

- 使用 Spark 方案，不連結帳務帳戶。
- 使用 Authentication、Cloud Firestore 與 Security Rules。
- 不使用 Cloud Functions、Storage、付費簡訊或其他需 Blaze 的功能。
- 若免費額度耗盡，服務可能暫停；不得自行升級為付費方案。

## 安全邊界

正式版以 Google 帳號識別人員、以 NFC Tag 識別打卡位置，並由 Firestore 保存伺服器時間。固定 NFC 網址仍可能被轉傳，因此不能單獨當成絕對位置證明。正式人事使用前仍須完成實體手機驗收、個資告知、保存期限、備份與異常處理規範。

## 月報計算規則

- 預設上班 09:00、下班 18:00、遲到寬限 5 分鐘。
- 預設工作日為週一至週五；國定假日及實驗室休假日由系統總管在「出勤設定」加入排除日期。
- 核准的請假與公出不列入缺勤。
- 原始 NFC 打卡時間不直接修改；補登與更正採申請、審核及留痕方式處理。

## 本機預覽

```bash
python3 -m http.server 4173
```

然後開啟 `http://localhost:4173`。
