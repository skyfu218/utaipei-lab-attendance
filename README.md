# 臺北市立大學運動能力分析實驗室打卡系統

手機掃描 NFC Tag 的行動出勤 Web App 第一版。

## 目前可操作功能

- 同仁／系統總管示範入口
- NFC 簽到與簽退流程模擬
- 重複掃描防止重複紀錄
- 個人及全體出勤紀錄
- 請假、補登及更正申請
- 異常與申請中心
- 出勤事件訊息中心
- 人員與 Tag 管理畫面
- CSV 匯出
- 響應式手機介面與 PWA 基礎

## 測試網址參數

- 簽到：`?tag=lab-checkin`
- 簽退：`?tag=lab-checkout`

## 安全邊界

目前版本使用瀏覽器本機示範資料，不可作為正式人事出勤依據。正式使用前必須接入：

1. 受保護的使用者登入與角色權限。
2. 伺服器端資料庫與伺服器時間。
3. 安全型動態 NFC Tag 的一次性驗證。
4. 完整的資料存取規則、稽核紀錄與備份。
5. 個資告知、保存期限與管理規範。

## 本機預覽

```bash
python3 -m http.server 4173
```

然後開啟 `http://localhost:4173`。
